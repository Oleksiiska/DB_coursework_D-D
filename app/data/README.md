# Списки, складені вручну

Невеликі довідники без відкритого джерела (у додатку А звіту — джерело СП).
Входять до образу застосунку разом із кодом.

| Файл | Що містить | Хто використовує |
|---|---|---|
| `settings.json` | 13 ігрових світів: назва, опис, жанр, тональність, суміжні світи | `CsvLoader` публікує їх у чергу першими, з `origin = manual`; генератор обирає світ пригоди |
| `systems.json` | ігрові системи з редакціями, базовими книгами, псевдонімами для розпізнавання в тексті та вагою для генератора | генератор (`system`, `edition`, `required_books`), розбір карток каталогу |
| `publishers.json` | видавництва з вагою для генератора | генератор (`publisher`, лише для згенерованих пригод) |
| `tag_aliases.json` | канонічні теги та варіанти їх написання | `VocabularyNormalizer`: зведення тегів до словника |

`setting_id` — фіксований UUID версії 5 від slug світу в просторі імен
`uuid5(NAMESPACE_URL, "https://github.com/Oleksiiska/DB_coursework_D-D/settings")`,
тож повторне завантаження не змінює ключів.

Псевдоніми тегів доповнюються за журналом нерозпізнаних значень
(п. 2.11 звіту). Для тегів, яких немає в групах бічного фільтра itch.io,
сюди можна додати поле `category` — категорію, задану вручну.
